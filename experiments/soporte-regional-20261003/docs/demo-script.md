# Demo local de hasta cinco minutos

Duración objetivo: 4 minutos 40 segundos. Preparación previa: iniciar la aplicación, tener artefactos compatibles y revisar `integration-check.json`; no entrenar durante la demo.

| Tiempo | Acción y mensaje |
|---|---|
| 0:00–0:35 | Presentar el problema: estimar t/ha por parcela de cebada en tres estados, campaña abril–octubre 2025. Mostrar el corte y aclarar el alcance retrospectivo. |
| 0:35–1:15 | Mostrar las 197 parcelas, filtrar un estado y buscar una parcela. Diferenciar observado y oculto, superficie y procedencia. |
| 1:15–2:00 | Pulsar «Calcular rendimiento estimado». Mostrar rendimiento, producción = rendimiento × superficie, versión y ficha descargable. Explicar que el botón carga y ejecuta un modelo guardado. |
| 2:00–2:40 | Cambiar sensor. Mostrar puntos originales/utilizables y curva reconstruida. Abrir un ejemplo con laguna del archivo `curve-quality.csv` y explicar por qué no se atribuye floración exacta. |
| 2:40–3:35 | Abrir «Validación»: RMSE/MAE/R² de 138 predicciones externas, tres estados y referencias. Distinguir evaluación espacial de test oculto. Informar si se admitieron intervalos y su limitación. |
| 3:35–4:15 | Abrir «Fuentes», explicar criterio de admisión de NASA/DGSIAP y modelo oficial independiente. Descargar las 59 filas manteniendo un filtro para comprobar alcance. |
| 4:15–4:40 | Mostrar trazabilidad y ejecución local. Cerrar con límites: una campaña, pocos datos, sin garantías por parcela ni uso directo para aprobar crédito. |

Pendientes de entrega externa: elegir alojamiento y URL, revisar formato/redondeo exigido por plataforma, completar integrantes/aportaciones y confirmar anexos. El paquete local no publica el proyecto ni realiza el envío oficial.
